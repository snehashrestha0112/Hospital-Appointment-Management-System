# Sneha Health Care

Sneha Health Care is a plain PHP, HTML, and CSS hospital management system. It does not use Bootstrap, jQuery, Font Awesome, or any other frontend framework in the active app.

## Features

- Patient registration and login
- Separate patient login and registration pages
- Patient appointment booking
- Patient appointment history
- Doctor login
- Doctor appointment list
- Admin login
- Admin doctor list
- Admin patient list
- Admin add/remove doctor management

The system is intentionally limited to the features listed above.

## Setup

1. Start Apache and MySQL in XAMPP.
2. Import `myhmsdb.sql` into MySQL.
3. Open `http://localhost/project/index.php`.
